# RepoLens Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local web dashboard that displays public GitHub repository metrics and optionally produces an explained AI project-health assessment.

**Architecture:** A React client calls a FastAPI backend that normalizes GitHub data and keeps credentials private. Separate GitHub, cache, aggregation, and AI services allow deterministic testing without live providers. Metrics remain available independently of AI.

**Tech Stack:** React, TypeScript, Vite, FastAPI, Pydantic, httpx, pytest, Vitest, React Testing Library; CSS/SVG charts with accessible textual equivalents.

**Spec:** `docs/superpowers/specs/2026-09-28-repolens-design.md` (read before execution).

## Global Constraints

- GitHub and AI credentials stay on the backend.
- The first version runs locally.
- No database is required.
- Failed responses are not cached.
- The provider URL cannot be supplied by dashboard users.
- Repository text is untrusted evidence, never instructions.
- Only the most recently submitted repository may update the visible result.
- The dashboard must function without AI credentials.
- Missing evidence is disclosed, not invented.
- No accounts, private repositories, cloning, source-code quality analysis, persistent history, comparisons, or deployment.
- Offline fixtures, browser checks, live GitHub checks, and live AI checks are separate evidence categories.

## Shared contracts

Task 1 defines these Pydantic models; Task 6 mirrors them in TypeScript. Datetimes serialize as UTC ISO 8601; week starts are Unix seconds. Unknown values are null, never zero.

```python
class RepositoryRequest(BaseModel):
    model_config = ConfigDict(extra="forbid")
    url: str = Field(min_length=1, max_length=2048)

class Language(BaseModel):
    name: str
    bytes: int = Field(ge=0)
    percentage: float = Field(ge=0, le=100)

class CommitWeek(BaseModel):
    week_start: int
    commits: int = Field(ge=0)

Availability = Literal["available", "empty", "pending", "unavailable"]

class Analysis(BaseModel):
    full_name: str
    url: str
    description: str | None
    license: str | None
    pushed_at: datetime | None
    stars: int
    forks: int
    open_issues: int | None
    open_pull_requests: int | None
    languages: list[Language]
    activity: list[CommitWeek]
    availability: dict[str, Availability]
    warnings: list[str]
    retrieved_at: datetime
    ai_available: bool

class Dimension(BaseModel):
    score: int | None = Field(default=None, ge=0, le=100, strict=True)
    explanation: str = Field(min_length=1, max_length=2000)
    evidence: list[str]

class Assessment(BaseModel):
    full_name: str
    status: Literal["assessed", "insufficient_evidence"]
    overall_score: int | None
    dimensions: dict[str, Dimension]
    evidence: dict[str, str]
    limitations: list[str]
    provider: str
    model: str
    assessed_at: datetime
```

Availability keys are exactly `issues`, `pull_requests`, `languages`, `activity`, and `readme`. Required dimensions are exactly `maintenance`, `documentation`, and `community`. The error envelope is `{ "error": { "code": str, "message": str, "retry_after_seconds": int | null } }`. Error handlers convert request validation and domain failures into this envelope. Never return raw exception strings.
